# Proyecto-Practicas-Profesionalizantes-I
Análisis de la brecha digital y las condiciones socioeconómicas de los hogares argentinos.
Brecha Digital y Condiciones Socioeconómicas de los Hogares Argentinos

Descripción del proyecto

Este proyecto busca analizar la relación entre las condiciones socioeconómicas de los hogares argentinos y su acceso a la tecnología.

Se trabajará con variables relacionadas con los ingresos familiares, el nivel educativo, la tenencia de computadoras y el acceso a Internet fijo, tomando como referencia la Encuesta Permanente de Hogares (EPH) del INDEC.

Perfil profesional

Somos estudiantes en formación en Ciencia de Datos e Inteligencia Artificial, interesados en utilizar herramientas de programación y análisis estadístico para interpretar información y encontrar soluciones a distintos problemas.

En este proyecto aplicamos conocimientos de Python y análisis de datos para organizar información, identificar posibles tendencias y comunicar resultados de manera clara.

Alcance del servicio

El análisis busca:

Identificar posibles diferencias en el acceso a la tecnología según las condiciones socioeconómicas.

Analizar los ingresos y el nivel educativo de los hogares.

Elaborar estadísticas descriptivas y gráficos.

Presentar conclusiones que puedan servir como referencia para la toma de decisiones.

Herramientas utilizadas:

Python.

Pandas.

NumPy.

Matplotlib.

Google Colab.

GitHub.

Datos utilizados

Se utiliza un conjunto de datos sintético generado mediante Python, basado en variables de referencia de la EPH. Los registros no corresponden a hogares reales encuestados por el INDEC.

Resultados esperados

Se espera identificar patrones y posibles desigualdades en el acceso a la tecnología, para comprender mejor la problemática de la brecha digital.
